Ask for access to the members' room

The members' reading room is private. People the church's officers name are given read access through a GitHub team called readers; nothing in it can be changed by a reader.

  1. Write to the church at info@psanctuary.org or through the contact form, saying who you are and why you would like to read.
  2. Give your GitHub username when asked. Never send a password, a code or a key: nobody here will ask for one.
  3. Accept the invitation GitHub sends you (by email, or the bell icon on github.com), with two-factor authentication turned on.
  4. Open the room in your browser. Every page has a PDF beside it, if you would rather print or send it on.
