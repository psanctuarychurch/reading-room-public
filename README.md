## 📖 How this room works

The church's people read drafts first, in a private members' room. When the church's officers decide a page is ready
for visitors, they add it to that room's list of pages to share, and an automatic copy brings it here. The copy checks
every page before it leaves (no private names, no keys or passwords) and records what it brought in
`SYNCED-FROM-reading-room.txt`, which the front page reads to list them.

| This repository holds | Written by |
| --- | --- |
| `index.html`, this `README.md`, `.nojekyll` | by hand, by pull request |
| every other page, and `SYNCED-FROM-reading-room.txt` | the automatic copy only; never edited here |

The front page is plain HTML with no build step: it works on a phone, follows your light or dark setting, and is served
by GitHub Pages from `main`. `main` has a deletion-only rule, because the automatic copy writes to it.

## 🔑 Asking for access to the members' room

Write to the church at [info@psanctuary.org](mailto:info@psanctuary.org) or through
[the contact form](https://www.psanctuary.org/contact), and give your GitHub username when asked. Never send a
password, a code or a key; nobody here will ask for one.
